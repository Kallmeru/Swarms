Immune system for AI agent swarms

Agents hand work to other agents: a reader to an analyst, an analyst to an emailer. One poisoned document can ride that chain like a virus, infecting each agent that reads it in turn. SWARMS labels every value trusted or untrusted the moment it enters the system, and strips a command's authority the instant it crosses a boundary it did not earn.

How it works

1

Read

An agent reads a document. Anything from outside the system is labeled untrusted the moment it enters, no matter how it's read.

2

Hand off

Data can cross the boundary between agents. Authority cannot. Every handoff strips capability, so an infected agent carries information forward, never a command.

3

Contain

When an agent attempts a privileged action, two things are checked: did the human authorize this action, and does every argument that steers it trace back to the human. An injected recipient fails the second. Nothing about the wording is examined.

The body of that email may quote the untrusted document freely. Only the arguments that decide what the action does have to be grounded, which is why ordinary work still completes rather than being blocked along with the attack.

Run it yourself

The hosted demo replays recorded runs. Run the backend and the same page executes the pipeline live, including on any document you type into the console.

git clone https://github.com/Kallmeru/Swarms.git && cd Swarms
pip install -r requirements.txt

python -m server                     # then open http://localhost:8000
