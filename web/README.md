# SWARMS: frontend

Static site, no build step.

- `index.html`: the dashboard, project overview, real benchmark stats, and the team. The entry point.
- `os.html`: the SWARMS OS demo itself, reads everything from `web/data/` and animates the swarm graph.

## Run locally
```
python -m http.server 8000 --directory web
```
then open http://localhost:8000

## Data contract
Every file in `web/data/` is generated by `benchmark/run_benchmark.py`, which calls `swarm.run_swarm.run_swarm()` for each fixture in `swarm/attacks/`:
- `manifest.json`: list of attacks for the dropdown
- `benchmark_summary.json`: aggregate success rates, read by both `os.html`'s chart and the dashboard's stats
- `<attack_id>_off.json` / `<attack_id>_on.json`: ordered event arrays to animate, one pair per attack

All 8 attacks in `web/data/` are real output from running the benchmark script, not placeholders. The event schema is documented in full in `docs/swarms-integration-schema.md`.

Nothing in `web/` calls an LLM or executes anything. It is a pure read-only visualization of pre-generated JSON.
